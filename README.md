# Git and GitHub Assignment 1
## Overview
This repository contains practical exercises demonstrating Git version control and GitHub
collaboration.
## Topics Covered
- Local repository initialization
- Staging, unstaging, and committing changes
- Remote repositories and push/pull operations
- Branch creation and management
- Pull requests and merging
- Soft, mixed, and hard resets
- Partial staging using `git add -p`
- Comparing branches using `git diff`
- Merge conflict resolution
- Removing files and reverting commits
- Forking repositories and contributing changes
